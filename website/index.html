BEFORE YOU DIG IN

A few small
details.

Is SmallGit free?+

Yes. SmallGit is a free, open-source Git GUI for macOS, built with Swift and SwiftUI. The MIT license permits personal and commercial use, with the required copyright and license notices.

What do I need to run SmallGit?+

macOS 14 or later and Git installed on your Mac. The current prebuilt download is for Apple silicon (arm64). Intel and universal downloads are not available yet.

How do I install it?+

{{INSTALL_TEXT}} Unzip the download and drag SmallGit.app into Applications. The release includes a SHA-256 checksum and build details.

The download is signed with Developer ID and notarized by Apple, with the notarization ticket included in the app. The release pipeline checks Gatekeeper acceptance after extracting the final ZIP.

Does it replace every SmartGit feature?+

SmallGit focuses on common everyday Git workflows. It is an independent project. Cherry-pick UI and bisect are still in progress; dedicated GPG signing, Git LFS, and pull-request interfaces are planned. Interactive rebase does not yet support reword or edit.

Can I use the code in my own project?+

Yes. SmallGit uses the MIT license. Keep the required copyright and license notices. A credit to VUBA and a link back to SmallGit would be appreciated; that extra public credit is optional.

Where can I report a bug?+

{{SUPPORT_TEXT}} Include your app version, macOS version, and steps to reproduce. Please remove private repository details from screenshots and logs. For security issues, email dev@vuba.one privately.
